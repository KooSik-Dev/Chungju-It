# 충주잇다 사이트 설명서

> 충주시민이 생활 속 불편을 지도에 남기고, 이웃의 공감으로 우선순위를 만들어 가는 **시민 생활불편 공감신고 플랫폼**입니다.
> 이 문서는 ① 시민 사용법, ② 관리자 사용법, ③ 데이터·연동 구조, ④ 운영·배포 방법, ⑤ 제약 사항을 순서대로 설명합니다.
> (문서 기준 버전: 커밋 `f39c292` 이후, 2026-11-03)

## 2. 공통 화면 구성

- **상단 안내줄**: 서비스 소개 문구와 `가+` 글자 크기 버튼(기본/크게).
- **헤더**: 로고(누르면 민원지도로), 주 메뉴(민원지도·공감순위·처리현황·자료조사·이용안내), 언어 변경(지구본), 로그인/내 계정, `+ 민원 신고` 버튼.
- **회차 바**: 현재 회차 번호, 접수 기간(한국시간), `마감까지` 남은 시간, `회차 보기 →`.
  - 남은 시간은 **접수 기간 카드와 같은 7일 주기 종료 시각**을 기준으로 표시됩니다(두 타이머가 항상 일치).
- **접수 기간 카드(민원접수기간)**: 시민 화면에서는 슬로건 오른쪽, 관리자 화면에서는 `신고 업무 현황` 제목 오른쪽에 표시됩니다.
  - 접수 시작일 ~ 종료일, `D-6 | 23시간 | 59분 | 59초` 형식의 남은 시간, 안내 문구.
  - **7일 주기 반복**: 0초가 되면 자동으로 다음 7일 주기가 시작되고 날짜 표시도 함께 바뀝니다. 새로고침·재접속해도 초기화되지 않으며, 모든 사용자가 같은 주기·같은 남은 시간을 봅니다(서버 시각 기준).
- **모바일**: 상단 메뉴 대신 하단 탭(지도·순위·신고·현황·더보기)을 사용하고, 긴 화면은 카드/바텀시트 형태로 표시됩니다.

## 3. 시민 사용법

### 3.1 첫 방문

1. 처음 접속하면 **언어 선택 화면**이 뜹니다. 8개 언어 중 하나를 고르면 기억됩니다.
2. 이어서 **게스트 이름 입력**을 요청합니다(4자리, 예: `게스트#단풍`). 이름을 정하면 바로 신고할 수 있습니다.
3. 회원으로 계속 쓰려면 로그인/회원가입으로 전환할 수 있습니다.
4. 나중에 설정을 바꾸려면 오른쪽 위 지구본(언어) 또는 `가+`(글자 크기)를 누릅니다.

### 3.2 민원 신고하기

1. 헤더의 `+ 민원 신고`를 누릅니다. (게스트는 이름 확인, 회원은 로그인 상태면 바로 폼)
2. 입력 항목

| 항목 | 필수 | 제한/설명 |
| --- | --- | --- |
| 분야 | ✔ | 가로등 · 신호등 · 시내버스 · 보도·도로 · 주차 · 안전·유해환경 · 청결 · 공공시설 |
| 제목 | ✔ | 최대 80자 |
| 내용 | ✔ | 최대 1,000자 |
| 위치 설명 | ✔ | 최대 100자, 예: `충주시 호암동 호암지 산책로` |
| **지도 위치** | ✔ | 지도를 눌러 지점을 지정해야 저장됩니다. `내 위치` 버튼으로 현재 위치를 사용할 수 있습니다 |
| 심각도 | 선택 | 매우 심각 · 빠른 조치 시급 · 위험함 · 주의가 필요함 · 불편함 |
| 사진 | 선택 | 최대 5장, 장당 5MB 이하(PNG·JPEG·GIF·WebP·AVIF) |

3. 위치를 지정하지 않으면 안내 문구와 함께 저장이 막힙니다(화면과 저장 단계 모두 확인).
4. `저장 전 미리 보기`로 확인한 뒤 저장하면, 목록·지도에 바로 반영됩니다.
5. 저장된 신고는 공개됩니다(제목·내용·위치·사진·공감·공개 댓글). 개인정보는 쓰지 마세요.

### 3.3 민원지도(홈)

- **검색**: 동네·장소·키워드로 신고 검색.
- **분야 칩**: 9개 분야 필터.
- **상태 필터**: 전체 상태 / 공감모집 / 시청전달 / 처리중 / 처리완료.
- **정렬**: 공감순 · 최신순.
- **지도**: 마커를 누르면 요약 팝업이 열리고 `자세히 보기`로 상세를 봅니다. 확대/축소·내 위치·지도 오류 시 `다시 시도`를 제공합니다.
- **목록 카드**: 사진, 분야, 제목, 위치, 공감 수, 공감 순위 배지 표시.
- **이야기 비교**: 최대 3개 신고를 나란히 비교(비교함은 브라우저에 저장).
- 지도 타일을 불러오지 못해도 목록·상세·신고 기능은 그대로 동작합니다.

### 3.4 신고 상세

상세 창에서 할 수 있는 일:

| 기능 | 설명 |
| --- | --- |
| 공감 | 하트를 눌러 공감(1인 1회). 공감 수가 순위에 반영됩니다 |
| 관심 저장 | 별표로 보관함에 저장 |
| 공유 | 기기 공유 기능 또는 링크 복사 |
| 사진 | 눌러서 원본 비율로 크게 보기, 여러 장 넘기기 |
| 공개 댓글 | 300자 이내, 모든 방문자에게 공개 |
| 진행 상황 | 현재 상태 단계와 공개 진행 기록 확인 |
| 수정 | **내가 쓴 신고**만 가능(사진 추가·삭제 포함) |
| 삭제 | 시민 화면에는 없습니다. **삭제는 관리자 화면에서만** 가능합니다 |

### 3.5 공감순위 · 처리현황 · 자료조사 · 이용안내

- **공감순위**: 공감모집 상태 신고를 공감 수 기준으로 정렬해 TOP 순위를 보여 줍니다. `회차 보기`에서 현재 회차 기간·TOP 3·지난 회차 기록을 확인합니다.
- **처리현황**: 공감모집 → 시청전달 → 처리중 → 처리완료 단계별 현황과 신고 목록.
- **자료조사 / 이용안내**: 지역 자료와 이용 방법, 공식 신고 채널(충주시청, 국민신문고, 안전신문고 등) 링크를 안내합니다. ※ 링크 이동만 제공하며 자동 접수 연동은 없습니다.

### 3.6 나의 동네 보관함(`/activity/`)

4개 탭으로 모아 봅니다: **관심 이야기 · 공감한 이야기 · 내 신고 · 댓글이 있는 이야기**. 회원의 관심·설정은 비공개, 신고·댓글·사진은 공개입니다.

### 3.7 게스트 계정

- 게스트 이름은 4자리(예: `단풍`)이며 중복 사용할 수 없습니다.
- 이름을 잃어버리면 **복구 코드**(`CJI1.…`)로 되찾을 수 있습니다. 코드는 계정 관리에서 다시 확인할 수 있습니다.
- 게스트 상태에서도 신고·공감·댓글·수정이 가능하며, 나중에 회원으로 전환할 수 있습니다.

### 3.8 접근성 · 편의

- 글자 크기 키우기(가+), 키보드 탐색(Tab·Enter), `Esc`로 창 닫기.
- PC에서 `Ctrl / ⌘ + K`로 검색으로 바로 이동.
- 모바일에서 버튼을 누를 때 짧은 진동(햅틱)을 지원하며, 기기 설정을 따릅니다.

## 4. 관리자 사용법 (`/admin`)

### 4.1 로그인과 권한

- 관리자 화면은 **회원 계정 로그인** 후 업무 기능(상태 변경·댓글·진행 기록·업무 메모·삭제·회차 관리)을 사용할 수 있습니다.
- 로그인 전에도 지도·목록·신고 내용은 볼 수 있지만, 변경/삭제 버튼은 로그인 안내로 바뀝니다.
- 시민 화면으로 이동하는 버튼은 관리자 화면에 두지 않았습니다.

### 4.2 첫 화면 — 신고 위치 지도

- 상단에 `신고 업무 현황`과 민원접수기간 카드, 계정 영역이 있습니다.
- **지도가 먼저** 보이고, 실제 좌표가 저장된 신고만 마커로 표시됩니다.
- 마커에는 시민 화면과 같은 **공감 순위 번호**와 색이 적용됩니다.
- 마커를 누르면 요약 팝업이 열리고, 목록에서 골라도 지도가 그 위치로 이동·확대되며 팝업이 함께 열립니다.
- 팝업이 지도 아래로 잘리지 않도록 자동으로 지도를 조정합니다.

### 4.3 목록 · 필터 · 정렬 · 내보내기

| 구분 | 항목 |
| --- | --- |
| 검색 | 제목 · 내용 · 위치 |
| 분야 필터 | 시민 화면과 동일 9개 |
| 진행 의견/진행 단계 필터 | 접수 확인 · 검토 중 · 보완 요청 · 승인 제안 · 반려 제안 · 조치 진행 · 완료 의견 · 보류 |
| 신고 상태 필터 | 전체 / 처리 전·진행 중 / 처리 완료 |
| 정렬 | **공감 순위순(기본)** · 최신순 · 공감순 · 댓글순 · 내 우선순위순 · 심각도순 · 확인 예정일순 |
| 초기화 | `필터 초기화` |
| 내보내기 | `CSV 내보내기` |

### 4.4 상세 보기(자세히보기) — 화면 이동 없는 팝업

- 팝업의 `상세 확인` 또는 상세 화면의 **`자세히보기`**를 누르면, **페이지가 스크롤되거나 다른 화면으로 이동하지 않고** 현재 화면 위에 상세 팝업이 열립니다.
- 팝업 내용: 제목, 전체 내용, 접수 일시, 심각도, 처리 상태, 위치 + 위·경도(좌표 복사), 첨부 사진(눌러서 확대·여러 장 넘기기), 위치 미니 지도, 공감·댓글·공개 기록 수, 공개 진행 기록.
- 지도는 팝업 뒤에 그대로 남아 있고, **배경 클릭 또는 `×`**로 닫으면 확대·중심·선택 상태가 유지된 같은 지도로 돌아옵니다.
- PC는 넓은 팝업(최대 760px), 모바일은 바텀시트로 열리며 내용이 길면 **팝업 내부에서 스크롤**됩니다.

### 4.5 상세 화면의 관리 기능

- **신고 처리 상태**: `처리 완료하기` / `처리 다시 진행` (시민 화면의 진행 상황과 공유됩니다).
- **공개 댓글**: 빠른 답변 문구(접수 확인·추가 정보 요청·진행 안내)를 쓰거나 직접 작성, 300자 이내.
- **공개 진행 기록**: 진행 단계 + 내용(1,000자 이내). 시민 상세·처리현황에 함께 표시됩니다.
- **나의 업무 메모(비공개)**: 우선순위·업무 상태·확인 예정일·메모를 계정에 비공개로 저장.
- **복사**: 신고 내용 복사 · 좌표 복사(사진 아래 위치).
- **삭제**: 신고 자체, 공개 댓글, 진행 기록 삭제. 삭제는 관리자만 가능합니다.
- 저장 실패가 의심되면 `저장 여부 확인` 버튼이 나타나 중복 저장을 막습니다.

### 4.6 회차 관리

- `회차 보기`에서 현재 회차 기간·마감까지 남은 시간·현재 공감 TOP 3·지난 회차 기록을 확인합니다.
- 로그인 상태에서 **다음 회차 기간(1·7·14·30일)** 을 고르고 `회차 종료 기록`으로 현재 회차를 마감할 수 있습니다.
- 회차를 마감하지 않아도 접수 기간 카드와 상단 `마감까지`는 7일 주기로 자동 반복됩니다.

### 4.7 단축키

- `Ctrl / ⌘ + K`: 관리 검색으로 이동
- `Esc`: 열린 창 닫기 / `Tab`·`Enter`: 항목 이동·실행

## 5. 데이터 · 연동 구조

### 5.1 외부 서비스 API (실제 호출하는 것)

| 서비스 | 엔드포인트 | 용도 | 인증 |
| --- | --- | --- | --- |
| **koosik.kr 페이지 API** | `https://www.koosik.kr/api/page/{페이지}`<br>`/collections/{이름}` · `/{id}`<br>`/protected/collections/...`<br>`/auth/register`·`login`·`me`·`logout`<br>`/upload` | 신고·댓글·공감·관심·프로필·회차·진행기록·관리자 메모 저장, 로그인, 사진 업로드 | 요청 헤더 `Authorization: Bearer <페이지 토큰>` + 로그인 시 `X-Page-Session` |

| **OpenFreeMap 지도 타일** | `https://tiles.openfreemap.org/styles/positron` | 지도 배경(스타일·타일·라벨) | 키 없음 |

- 그 밖의 외부 URL은 **이동용 링크**입니다: 충주시청, 국민신문고, 안전신문고, 공공데이터포털.
- 폰트·스크립트·이미지는 모두 자체 번들에 포함(외부 CDN·분석 도구 없음).

## 7. 제약과 주의 사항

1. **외부 백엔드 의존**: 데이터·계정·사진은 koosik.kr 페이지 API에 저장됩니다. 해당 서비스가 응답하지 않으면 조회·저장이 되지 않으며, 화면에는 재시도 안내가 표시됩니다.
2. **실시간 아님**: 공감·댓글·진행 기록은 새로고침 시 최신 목록을 확인하는 구조입니다(실시간 채팅 아님).
3. **번역 개인정보**: 번역을 쓰는 화면에서 사용자가 쓴 글 일부가 제3자(MyMemory)로 전송됩니다. 입력 폼 원문과 개인정보성 문구는 전송 대상에서 제외했지만, 민감한 내용은 번역 기능을 끄고 작성하는 편이 안전합니다.
4. **페이지 토큰은 공개 값**: 클라이언트에 포함된 페이지 토큰은 비밀 보호용이 아니며, 실제 보호는 로그인 세션(`X-Page-Session`)이 담당합니다.
5. **좌표 없는 옛 신고**: 예전에 저장된 좌표 없는 신고는 삭제·자동 변환하지 않으며, 지도에는 표시되지 않고 목록/상세에서만 조회됩니다.
6. **지도 타일 장애**: 타일 서버가 막히면 지도 배경만 비고, 마커·좌표·신고 기능은 유지됩니다.
7. **삭제 권한**: 삭제는 관리자 화면에서만 가능하며, 시민 화면에는 삭제 버튼이 없습니다.
8. **주기 기준**: 접수 기간은 **7일 고정 주기**로 반복됩니다.
   - 서버에 회차 기록이 있으면 그 회차 시작 시각을 기준으로 계산합니다.
   - 회차 기록이 아직 없거나(첫 배포 직후, 회차 종료 후) 비어 있으면 **2026-01-01 00:00(KST) 고정 기준일**부터 7일 주기로 계산해 표시합니다. 이때도 모든 사용자가 같은 기간·같은 남은 시간을 보며, 페이지 방문만으로 서버에 데이터를 쓰지 않습니다. 관리자가 `회차 보기 → 첫 회차 시작`을 누르면 그 회차 기록이 우선합니다.
   - 그래서 어떤 경우에도 `접수 기간 준비 중`은 표시되지 않습니다.
9. **회원/게스트 차이**: 관심 저장·설정은 로그인 계정에 비공개로 저장되고, 게스트는 브라우저 기준으로 동작합니다.

## 8. 자주 묻는 질문(FAQ)

**Q. 신고가 저장되지 않습니다.**
A. 지도 위치를 지정했는지 확인하세요. 위치 미지정 시 저장이 막힙니다. 사진은 5장·장당 5MB 이하인지도 확인해 주세요.

**Q. 남은 시간이 0이 되면 어떻게 되나요?**
A. 접수 기간이 7일 주기로 자동 반복되어 곧바로 다음 주기가 시작됩니다. 날짜 표시도 함께 바뀌고, 새로고침해도 초기화되지 않습니다.

**Q. 시민 화면과 관리자 화면의 남은 시간이 다르게 보입니다.**
A. 두 화면 모두 서버 시각 기준으로 계산합니다. 기기 시계가 크게 어긋난 경우 잠시 후 서버 시각으로 보정되며, 상단 `마감까지`와 접수 기간 카드는 항상 같은 시각을 씁니다.

**Q. 관리자 화면에서 신고를 눌렀더니 화면이 아래로 내려갑니다.**
A. 마커/목록 선택은 지도로 이동하는 동작이고, **상세는 `자세히보기`(또는 팝업의 `상세 확인`)로 열면 페이지 이동 없이 팝업으로 표시**됩니다.

**Q. 사진이 여러 장인 신고는 어떻게 보나요?**
A. 사진을 누르면 확대 창이 열리고 좌우 버튼(또는 스와이프)으로 넘겨 볼 수 있습니다.

**Q. 신고를 지우고 싶습니다.**
A. 시민 화면에서는 삭제할 수 없습니다. 관리자 화면에서 해당 신고를 열어 삭제해야 합니다.

**Q. 언어를 바꾸면 제가 쓴 글이 자동 번역되나요?**
A. 화면 문구는 즉시 바뀌고, 공개 글은 번역되어 표시됩니다. 번역 서비스 한도에 걸리면 원문이 그대로 보입니다.
