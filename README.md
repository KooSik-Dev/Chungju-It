# 충주잇다

충주시민 생활불편 공감신고를 체험하는 정적 웹앱입니다. **공식 민원 접수 창구가 아닙니다.** 예시 민원과 처리 상태, 회차는 실제 접수·시청 전달 내역이 아닙니다. 예시 위치는 대략적인 대표 좌표이며 사진은 AI 생성 예시입니다.

## 바로 실행하기

저장소의 `chungju-eatda.html` 파일을 다운로드해 브라우저에서 여세요. 직접 빌드한 경우에는 `dist/index.html` 파일을 열면 됩니다. 사진·스타일·스크립트가 모두 파일 안에 포함되어 있습니다. 지도에는 인터넷이 필요합니다. 브라우저 정책에 따라 `file://`에서 지도 또는 localStorage가 제한되면 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/`으로 접속하거나 HTTPS 정적 호스팅을 사용하세요.

## 개발과 배포

```bash
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 생성
npm run preview   # 빌드 확인
(cd dist && zip -r ../chungju-eatda-dist.zip .)
```

빌드 결과는 `dist/index.html` 하나입니다. ZIP을 만들면 압축을 풀었을 때 `index.html`이 바로 보입니다. HTTPS 정적 호스팅과 하위 경로에서도 사용할 수 있습니다. GitHub에는 소스가 올라가므로 소스에서 배포할 때는 빌드가 필요합니다.

## 지도

API 키 없이 [MapLibre GL JS](https://maplibre.org/) 공식 라이브러리와 [OpenFreeMap](https://openfreemap.org/)의 OpenStreetMap 기반 지도 데이터를 사용합니다. 지도 SDK는 빌드에 포함되지만 지도 스타일·데이터는 인터넷으로 불러옵니다. **기존의 공개 타일 무인증 사용 금지 조건과 달리**, 키 없이 실제 지도를 제공하기 위해 무인증 사용을 허용하는 OpenFreeMap의 공개 서비스를 사용합니다. OpenStreetMap의 공개 타일 서버를 직접 호출하지 않습니다. 외부 서비스이므로 장애나 정책 변경을 완전히 배제할 수 없습니다. 운영 전 제공자의 정책과 가용성을 확인하세요.

인터넷 연결, 콘텐츠 차단, WebGL 또는 지도 제공 서비스에 문제가 있으면 지도 영역에서 재시도할 수 있으며 목록·검색·공감·신고는 계속 사용할 수 있습니다. 브라우저에서 `file://` 지도를 차단하면 HTTPS 서버 또는 위의 로컬 서버를 사용하세요.

## 데이터와 사진

게스트 이름, 공감 기록, 관심 신고, 개인 메모, 테스트 신고와 사진은 브라우저 localStorage에만 저장되며 시청이나 다른 사용자에게 전송되지 않습니다. 민원 상세에서 공감·관심 저장과 개인 메모를 이용하고, 내가 작성한 테스트 신고를 수정하거나 삭제할 수 있습니다. 데이터가 없거나 손상되면 예시 데이터로 복구합니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 저장이 차단되거나 용량을 초과하면 안내됩니다. 테스트 신고의 위치는 신고 폼의 지도를 눌러 선택하거나 좌표를 직접 입력할 수 있습니다. 기본값은 신고 당시 지도 중심이며 지도가 없다면 충주시 중심이므로 저장 전에 확인해 주세요. 개인정보나 민감한 사진은 입력하지 마세요.

`public/images/`의 예시 사진과 페이지 대표 이미지는 이 프로젝트를 위해 AI 이미지 생성 기능으로 제작했습니다. 실제 충주 현장이나 신고 사진은 아닙니다. 빌드 시 HTML 안에 포함되며 대체 사진도 함께 포함됩니다. 대표 이미지는 화면에 사용되는 고해상도 파일이므로 이전 버전보다 다운로드 용량이 큽니다.

## 모의 회차와 편의 기능

접속한 시각부터 7일 동안 이 브라우저에서만 모의 회차가 진행됩니다. 상단 `회차 보기`에서 초 단위 남은 시간과 공감 모집 중인 신고의 **누적 공감 수** 기준 상위 3건을 확인하고, 다음 회차 기간을 선택하거나 직접 모의 종료할 수 있습니다. 종료 후 상위 3건은 이 브라우저에 기록되며 다음 회차가 시작됩니다. 자동 종료 처리는 앱이 열려 있을 때 또는 다시 열 때 이뤄지며, PC/휴대폰의 시간 설정에 영향을 받습니다. 기록은 최근 30회까지입니다. **서버나 시청으로는 아무것도 전송되지 않으며 실제 회차별 집계가 아닙니다.**

상단에서 한국어/영어를 전환하고 글자 크기를 키울 수 있으며, 설정은 브라우저에 저장됩니다. 예시 신고는 영어로 제공되고 사용자가 직접 쓴 신고와 메모는 원문 그대로 유지됩니다. 신고 상세의 내용 복사, 관심 신고·내 공감 필터, 나만의 메모를 사용할 수 있습니다. `Ctrl+K`(Mac은 `⌘K`)를 누르면 검색으로 이동합니다. 실제 민원 접수나 시청 전달에는 별도의 서버, 인증, 공식 수신처 협의가 필요합니다.

## 게스트 로그인과 리뉴얼 화면

로그인은 실제 계정 인증이 아니라 이 브라우저에서 표시명과 세션 표시를 사용하는 체험 기능입니다. 비밀번호는 없으며 다른 기기와 동기화되지 않습니다. 로그인 유지 선택 시 localStorage, 선택 해제 시 해당 탭의 sessionStorage에 세션 표시를 저장합니다. 로그아웃은 세션만 해제하며 신고·공감 등은 삭제하지 않습니다. 서로 다른 게스트 이름으로 들어와도 같은 브라우저의 활동을 공유하므로 개인 계정 간 분리 기능은 아닙니다. 프로필에서 표시명을 바꾸고 내 신고·관심·공감 목록으로 이동할 수 있습니다.

공감순위는 공감 모집 중인 신고의 누적 공감 TOP 3와 모집 중/전체 순위 목록을 표시합니다. 상세 화면의 설명과 4단계 진행 표시, 처리현황은 예시 또는 이 기기의 테스트 신고 상태이며 실제 처리 이력이나 시청 접수 정보가 아닙니다.

지도에는 공감 모집 중인 신고의 누적 공감 상위 3건을 목록 배지와 같은 1·2·3 숫자로 표시합니다. 지도 상단 빠른 선택을 누르거나 목록 카드를 누르면 해당 위치로 이동하며, 지도 표시를 누르면 요약과 상세 보기를 열 수 있습니다. 숫자는 필터 결과 순위가 아니라 전체 데이터의 TOP 3이며, 필터에 맞는 신고만 지도에 표시됩니다. 초록 점은 다른 공감 모집 신고, 회색 점은 그 외 상태입니다. 지도 및 위치는 예시 데이터이고 실제 시청 접수 위치를 의미하지 않습니다.

## 디자인과 접근성

커뮤니티 피드, 지도와 필터, 랭킹, 모바일 탭 바 등 다양한 디자인 패턴을 참고하되 특정 서비스 화면을 복제하지 않고 구성했습니다. 모바일의 `더보기`에서 자료조사와 이용안내를 찾을 수 있습니다. 카드·화면·상세 창의 짧은 전환과 공감 피드백을 제공하며, 기기에서 동작 줄이기를 설정하면 애니메이션을 최소화합니다. 첫 화면 동네 일러스트 역시 AI 생성 이미지이며 실제 장소가 아닙니다.

새 테스트 신고를 쓰는 동안 텍스트와 위치는 해당 탭의 sessionStorage에 임시 저장됩니다. 같은 탭에서 닫았다가 다시 열거나 새로고침하면 복구할 수 있고, 탭을 닫으면 사라집니다. 사진은 임시 저장되지 않으며 다시 선택해야 합니다. 신고를 저장하거나 임시 글을 지우면 임시 내용이 삭제됩니다. 저장이 차단된 경우 화면에서 알리고 새로고침 후 복구를 보장하지 않습니다. 개인정보는 입력하지 마세요.

## 탐색 개선

지도 컨트롤의 `⤢` 버튼은 현재 검색·필터에 일치하는 신고가 보이도록 지도를 맞춥니다. 신고 상세의 '함께 살펴볼 이야기'는 같은 카테고리를 우선하고 그다음 공감 수로 고른 이 기기의 예시·테스트 신고입니다. 카드 사진 버튼으로 키보드에서도 해당 위치로 이동할 수 있습니다. 메뉴 페이지는 주소의 `#map`, `#rank`, `#status`, `#research`, `#guide`에 반영되어 브라우저 뒤로/앞으로 가기와 새로고침을 지원합니다. 주소를 공유해도 다른 기기의 로컬 신고나 공감 기록은 공유되지 않습니다.
