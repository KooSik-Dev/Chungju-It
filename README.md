# 충주잇다

충주 생활 불편을 함께 살펴보는 단일 HTML 사이트입니다. ZIP을 풀어 `index.html`을 게시합니다. 지도와 API에는 인터넷이 필요하며, 제공된 페이지 API는 게시 후 사용할 수 있습니다.

## 주소와 배포

시민 화면은 `/main`, 공감순위는 `/ranking`, 처리현황은 `/status`, 자료조사는 `/research`, 이용안내는 `/guide`, 보관함은 `/activity`, 관리 화면은 `/admin` 주소로 직접 접속합니다. 시민 화면에는 관리 화면 링크가 없습니다. 기존 시민 화면 해시 주소도 이어집니다. ZIP을 풀 때 `index.html`, 각 경로의 `index.html`, `images` 폴더를 함께 같은 위치에 게시하세요. 경로별 파일은 메인 HTML을 같은 사이트에서 불러오는 작은 진입점이므로 정적 호스팅에서도 직접 접속과 새로고침을 지원합니다. 호스팅에 따라 디렉터리 주소 끝에 `/`가 붙을 수 있습니다. 사이트를 하위 폴더에 게시해도 해당 폴더 아래의 상대 경로를 사용합니다. HTML을 `file://`로 직접 열 때는 파일 시스템 경로를 바꿀 수 없어 관리자 화면에 `index.html#admin`을 직접 입력해 접근합니다. 경로를 숨기는 것은 접근 제어가 아닙니다.

## 관리 작업 화면

민원 신고는 지도에서 위치를 지정해야 접수됩니다. 좌표가 없으면 `민원 접수를 위해 지도에서 신고 위치를 먼저 지정해 주세요.` 안내가 표시되고 저장 요청도 전송되지 않으며, 저장 단계에서 한 번 더 같은 규칙으로 검증합니다.

메인 화면과 관리자 화면의 인사말 옆에는 `민원접수기간` 카드가 표시됩니다. 접수 시작·종료 날짜와 `D-6 | 23시간 | 59분 | 59초` 형식의 남은 시간이 1초 단위로 줄어들며, 값은 서버에 저장된 회차(기본 7일) 데이터를 기준으로 두 계정이 동일하게 표시합니다. 서버가 알려 준 시각(HTTP Date 헤더·저장 응답 시각)을 기준으로 계산해 기기 시계가 달라도 같은 남은 시간을 보여 줍니다.

관리자 상세의 `좌표 복사`는 첨부 사진 아래에 표시되어 사진과 겹치지 않고, 사진을 누르면 원본 비율로 확대됩니다. 지도 마커를 누르면 열린 팝업에서 `상세 확인`으로 같은 민원의 상세를 바로 열 수 있고, 모바일에서는 상세에서 `지도로 돌아가기`로 지도 화면으로 돌아옵니다.

관리 화면에 들어가면 신고 위치 지도가 먼저 보이고, 실제 좌표가 저장된 신고만 마커(사용자 화면과 같은 공감 순위 번호와 색)로 표시됩니다. 마커나 목록의 신고를 선택하면 지도가 그 위치로 이동·확대되고 팝업과 상세가 함께 열립니다. 신고 목록은 사용자 화면과 같은 TOP 3 공감 순위 배지를 표시하며 `공감 순위순` 정렬이 기본입니다. 상세의 첨부 사진을 누르면 원본 비율 그대로 확대되어 여러 장을 넘겨 볼 수 있습니다. `/admin`에서 신고 목록과 공감·댓글 집계, 분야·진행 의견 필터, 제목·내용·위치 검색, 최신·오래된 순·공감·댓글·내 우선순위·확인 예정일 정렬을 사용할 수 있습니다. 신고를 선택하면 시민의 공개 댓글을 확인하고 공개 답글을 남길 수 있습니다. 진행 상황과 승인·반려 **제안**은 공개 기록으로 남기며 시민 신고 상세와 처리현황에서도 보입니다. 공개 기록과 댓글은 실시간 채팅이 아니며 최신 목록은 새로고침으로 확인합니다. **삭제는 관리 화면(/admin)에서만 할 수 있습니다.** 관리 화면에서는 신고 자체와공개 댓글·진행 기록을 모두 삭제할 수 있고, 처리 완료 또는 처리 다시 진행으로 상태를 변경할 수도 있습니다. 시민 상세 화면에는 삭제 버튼이 없습니다. 관리 화면의 처리 완료 집계와 상태 필터, 시민 화면의 처리현황·신고 목록·상세가 같은 상태를 표시합니다. 신고의 사진·좌표와 ID 확인, 내용·좌표 복사, 공개 답변 문구도 지원합니다. 관리 화면에서는 시민 화면으로 이동하는 버튼을 표시하지 않습니다. Ctrl/Cmd+K는 관리 검색에 초점을 둡니다. 모바일 화면에서는 키보드 단축키 안내를 숨깁니다.

각 신고별 개인 업무 상태(대기·진행 중·완료), 우선순위, 확인 예정일, 태그, 체크리스트와 업무 메모는 보호 컬렉션 `admin-tasks`에 **본인만 볼 수 있는 비공개 항목**으로 저장합니다. 다른 사용자에게 공유되지 않습니다. 업무 상태·긴급·기한 지남·7일 이내·업무 미등록 빠른 필터와 초기화, 기한 집계는 계정별 개인 업무 기준입니다. 완료된 업무는 긴급·기한 집계에서 제외하며 날짜는 서울 기준입니다. CSV 내보내기는 현재 필터에 맞는 신고의 제목·분야·위치·내용·공감과 댓글 수·최신 진행 의견을 포함하며 비공개 업무 메모는 포함하지 않습니다. 신고 자체에 민감한 정보가 들어 있을 수 있으므로 내보낸 파일을 주의해서 다루세요.

**중요: 현재 API에는 관리자 역할·관리자 승인·권한 부여를 판별하는 기능이 없습니다.** 관리 화면의 가입은 일반 회원가입이며, 로그인한 모든 회원이 관리 화면에서 공개 진행 기록이나 답글을 작성하고 신고의 처리 상태를 바꿀 수 있습니다. 처리 완료는 이 사이트에서 공유한 상태이며 실제 행정기관의 처리를 인증하지 않습니다. 작성자를 인증된 관리자라고 표시하거나 실제 행정기관의 승인·접수로 취급하지 않습니다. 일반 공개 컬렉션의 타인 신고·댓글·진행 기록은 로그인한 사용자가 수정할 수 있고 관리 화면(/admin)에서 삭제할 수 있지만, 보호 컬렉션의 타인 기록(관심·설정·업무 메모)은 수정·삭제할 수 없고, 관리자 전용 비공개 채팅이나 여러 담당자가 공유하는 비공개 업무함도 제공되지 않습니다. 진짜 관리자만의 접근 제어와 승인 처리에는 API 차원의 관리자 역할과 권한 검증이 필요합니다.

## 회원가입과 로그인

제공된 페이지별 회원가입·로그인 API를 사용합니다. 아이디는 한글·영문·숫자로 시작하는 3~64자이며 `.`, `_`, `@`, `-`를 사용할 수 있습니다. 비밀번호는 8~128자입니다. 페이지별 프로젝트 ID와 정규화한 아이디로 소금을 만들고, 제공된 규격대로 PBKDF2-SHA-256 500,000회로 변환한 credential을 인증 API에만 전송합니다. 원문 비밀번호와 credential은 게시물이나 브라우저 저장소에 저장하지 않습니다. credential 자체도 인증에 사용될 수 있는 민감한 값이므로 노출하지 않아야 합니다. 통신과 사이트는 HTTPS로 보호되어야 하며, 이 페이지에는 비밀번호 복구 기능이 제공되지 않습니다.

로그인 후 세션은 해당 탭의 `sessionStorage`에만 보관합니다. 새로고침 시 `getCurrentUser`로 확인하며 401이면 세션을 지우고 다시 로그인하도록 안내합니다. 로그아웃은 API 호출 후 세션을 제거합니다. 탭이나 브라우저 환경에 따라 세션이 유지되지 않을 수 있으며, 다른 탭이나 기기에서는 로그인해야 합니다. 공유 기기에서는 사용 후 로그아웃하세요. 세션은 브라우저 스크립트가 읽을 수 있으므로 스크립트 침해에도 보호되는 HttpOnly 쿠키가 아닙니다.

## 신고와 회원 데이터

신고와 댓글, 공개 진행 기록은 일반 공개 컬렉션에 저장하며 로그인한 사용자는 누구나 수정할 수 있고, 삭제는 관리 화면(/admin)에서만 할 수 있습니다. **회원 관심과 화면 설정, 업무 메모**는 보호 컬렉션에 `private`으로 저장해 본인 세션으로만 불러옵니다. 공감은 보호 컬렉션의 공개 항목으로 저장하고 소유자 기준으로 집계하므로 로그인한 계정에서 다시 확인할 수 있습니다. 보호 컬렉션의 접근 통제는 API가 수행합니다.

처음 실행하면 언어 선택 화면이 먼저 열리고, 고른 언어는 기기에 저장되어 다음 실행부터는 표시되지 않습니다. 이후에는 헤더의 지구본(🌐) 버튼에서 언제든 언어를 바꿀 수 있고 현재 언어가 함께 표시됩니다.

새 방문 시 게스트 이름 입력창이 먼저 열리며, 닫고 사이트를 둘러볼 수도 있습니다. 로그인 버튼도 게스트 화면부터 열리고 아래의 회원 로그인 버튼에서 기존 회원 로그인·가입을 선택할 수 있습니다. 게스트로 시작한 뒤에는 로그아웃하지 않으면 기기에 저장된 코드로 다시 확인해 계속 이용하며, 게스트 계정 메뉴에서 복구 코드를 확인하거나 로그아웃할 수 있습니다. 로그아웃은 기기의 게스트 정보를 지우지만 서버의 이름 예약과 게시물은 삭제하지 않습니다. 같은 브라우저의 다른 탭에도 로그아웃을 반영하며, 복구 코드로 다른 기기 또는 로그아웃한 기기에서 다시 사용할 수 있습니다.

회원가입·로그인 또는 게스트 이름 설정 후 신고·댓글·공감·관심을 이용할 수 있습니다. 게스트는 고정된 `게스트#` 뒤의 이름을 직접 정하며, 이름을 정규화해 파생한 내부 아이디로 서버 가입 API에서 예약합니다. 같은 정규화 이름은 서버가 중복 가입을 거부합니다. 공개 `guest-names` 보호 컬렉션에 이름과 공개 기기 식별자를 저장합니다. 사용자가 별도로 아이디나 비밀번호를 입력할 필요는 없지만, 내부적으로 임의 비밀값을 발급해 서버 계정에 가입·확인합니다. 기존 게스트도 처음 이용할 때 이름을 예약해야 하며 이미 예약된 이름이라면 다른 이름을 선택해야 합니다.

게스트 시작 또는 이름 변경 시 복구 코드가 표시됩니다. **코드를 가진 사람은 해당 게스트로 복구할 수 있으므로 비밀번호처럼 안전하게 보관하고 공유하지 마세요.** 코드에는 무작위 비밀값과 공개 기기 식별자가 포함되며, 서버에는 PBKDF2로 파생한 인증값만 인증 API로 전송합니다. 코드는 1년 쿠키와 localStorage에 보관을 시도하므로 브라우저 스크립트나 기기 접근자에게 노출될 수 있습니다. 두 저장소가 모두 차단되면 별도 보관한 코드가 필요합니다. `복구 코드로 돌아오기`에서 코드를 입력하면 다른 기기에서 같은 게스트의 공개 활동을 불러옵니다. 코드를 잃으면 복구할 수 없으며 이름을 변경해도 기존 예약은 자동 해제되지 않습니다. 가입 응답이 유실되면 화면의 임시 코드를 보관하고 복구로 서버 저장 여부를 확인해야 합니다.

게스트 이름 예약과 달리, 게스트 신고·댓글·공감·관심은 기존과 같이 일반 공개 컬렉션을 사용합니다. **API를 직접 호출하면 누구나 해당 기록과 표시명을 위조·수정·삭제할 수 있으므로 이름이나 활동의 소유권 보호는 보장되지 않습니다.** 완전한 중복·사칭 방지에는 서버의 표시명 검증과 쓰기 권한 검증이 필요합니다. 새 회원 공감·관심은 보호 컬렉션에 저장하고, 신고·댓글·진행 기록은 일반 공개 컬렉션에 저장합니다. 게스트와 회원의 활동은 자동 병합되지 않습니다. 일반 컬렉션과 회차 설정은 API 자체에서 로그인 검증을 하지 않습니다.

신고 작성·수정 시 심각도(🔴 매우 심각 · 🆘 빠른 조치 시급 · ⚠️ 위험함 · 🟠 주의가 필요함 · 🟡 불편함)를 하나만 선택할 수 있고, 선택값은 신고 JSON의 `severity`에 저장됩니다. 심각도가 없는 기존 신고도 그대로 열리며 목록·상세에서는 `심각도 미지정`으로 표시됩니다. 관리 화면의 신고 목록은 제목·내용 요약·신고 날짜·위치·심각도를 한 줄에서 보여 주고 심각도순 정렬을 지원하며, 선택한 신고의 상세에는 저장된 좌표를 지도와 마커로 표시합니다. 좌표가 없는 신고는 지도 대신 `위치 정보 없음`으로 표시하고 오류를 내지 않습니다.

신고 작성 화면을 열면 위치 권한을 허용한경우 현재 기기 위치가 좌표에 자동 적용되며, `현재 위치 사용` 버튼으로 다시 불러올 수 있습니다. 위치는 저장하지 않고 좌표만 사용합니다. 사진은 한 신고에 최대 5장까지 올릴 수 있고, 장당 PNG/JPG/GIF/WebP/AVIF 5MiB 이하만 업로드합니다. 업로드한 사진 주소는 신고의 `images` 배열(최대 5개)에 저장하고 첫 장을 `image`에도 함께 기록하므로 기존 단일 사진 신고와도 호환됩니다. 신고 상세에서는 첫 사진을 크게 보여 주고, 사진이 여러 장이면 썸네일과 이전·다음 버튼, 사진 크게 보기(라이트박스)로 넘겨 볼 수 있습니다. 신고 수정에서는 사진을 더 올리거나 기존 사진을 뺄 수 있습니다. **사진 URL은 공개**이므로 민감한 사진을 올리지 마세요. 공개 신고·댓글에 개인정보를 입력하지 마세요. JSON 요청 본문 전체는 UTF-8 64KiB 이하입니다.

빈 목록은 정상이며 페이지별 목록을 `next_offset`이 null이 될 때까지 읽습니다. 수정 시 최신 항목과 revision을 읽고 변경된 필드만 합쳐 전체 데이터를 교체합니다. 충돌하면 새 버전을 읽어 알리고 입력을 유지하여 수동 재시도할 수 있습니다. 생성 응답이 유실되면 자동으로 다시 만들지 않고 목록에서 확인하도록 안내합니다. 가입 응답이 유실된 경우 중복 가입을 시도하지 않고 로그인으로 확인하도록 안내합니다. 401, 404, 409, 413, 429, 503과 네트워크 오류를 표시합니다.

회차 설정은 사이트에서 로그인한 회원이 변경할 수 있지만 API의 일반 공개 컬렉션에 저장됩니다. 회차 종료는 자동으로 수행되지 않고 종료 버튼을 눌렀을 때 상위 세 건을 기록합니다. 동시에 첫 회차를 시작하면 여러 항목이 만들어질 수 있습니다. 신고 상태는 이용자가 정리하는 공개 상태이지 행정기관 처리 상태가 아닙니다. 신고는 시청 민원으로 접수되지 않으므로 행정 처리가 필요한 경우 국민신문고 등 공식 창구를 이용하세요. 긴급 상황은 112 또는 119로 연락하세요.

처리 상태는 공개 `updates` 컬렉션에 JSON 상태 변경 기록으로 별도 저장합니다. 화면은 신고와 상태 기록을 함께 읽고 최신 상태를 적용하며 원본 신고는 삭제하거나 덮어쓰지 않습니다. 되돌릴 때는 새로운 처리 재개 기록을 추가합니다. 응답이 유실되면 저장 확인 후 재시도하며, 동시 변경은 기록의 순번과 서버 생성 시각 및 ID로 결정합니다. 서버가 관리자 역할을 검증하지 않으므로 전용 관리자만 상태를 변경하도록 강제하려면 서버 권한 기능이 필요합니다.

## 언어

한국어, 영어, 베트남어, 크메르어, 중국어(간체), 태국어, 러시아어, 일본어를 선택할 수 있습니다. 언어를 선택하면 사이트의 기본 UI 문구는 미리 작성한 언어별 내장 사전을 사용합니다. 공개 신고 제목·내용·댓글·공개 진행 의견은 API 키가 필요 없는 [MyMemory 공개 번역 API](https://mymemory.translated.net/doc/spec.php)로 자동 번역합니다. 한국어 화면에서도 다른 언어의 공개 게시물을 자동 번역합니다. 별도의 번역 버튼은 없습니다. 사전에 없는 일부 UI 문구는 원문으로 표시됩니다. 번역 결과는 화면에만 표시되고 원본 데이터는 바뀌지 않습니다.

**개인정보:** 자동 번역을 위해 공개 게시물의 제목·내용·댓글·진행 의견이 브라우저에서 MyMemory에 전송되며 서비스 제공자가 장기간 저장할 수 있습니다. 공개 게시물에도 민감한 정보가 포함될 수 있으므로 작성 시 주의하세요. [서비스 약관·개인정보 정책](https://mymemory.translated.net/terms-and-conditions)을 확인하세요. UI 문구와 입력 중인 값, 비밀번호, 복구 코드, 별도의 계정명·위치 필드, 개인 보관함 내용과 비공개 업무 메모는 자동 전송하지 않습니다. 단, 공개 게시물 본문에 직접 기재된 개인정보나 위치는 따로 걸러낼 수 없으므로 작성하지 마세요. 이를 위해 일부 개인 영역과 관리 화면은 외부 자동 번역에서 제외됩니다.

서비스의 익명 사용량은 통상 하루 5,000자이며 변경될 수 있습니다. 요청당 500바이트 제한에 맞춰 나누고, 중복 캐시와 동시 요청 제한을 사용합니다. 서비스 한도와 브라우저 통신 오류, 언어 감지나 번역 품질에 따라 일부 문구가 번역되지 않을 수 있으며 이때 원문을 표시합니다. MyMemory의 `autodetect` 동작은 공식 API 명세에 명시되어 있지 않아 변경될 수 있습니다. 실제 사이트의 브라우저 CORS 연결은 검증하지 않았습니다.

## 지도와 이미지

MapLibre GL JS와 OpenFreeMap 공개 벡터 지도를 사용합니다. 지도에는 인터넷과 WebGL이 필요하며 연결 실패 시 목록·검색·좌표 직접 입력은 계속 사용할 수 있습니다. ZIP에 포함된 분야별 이미지와 삽화는 AI 생성 이미지입니다. 새로 올린 사진은 API가 반환한 주소로 표시되며, 신고마다 최대 5장까지 표시합니다.
