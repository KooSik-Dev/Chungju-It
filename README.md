# 충주잇다

충주 생활 불편을 함께 살펴보는 단일 HTML 사이트입니다. ZIP을 풀어 `index.html`을 게시합니다. 지도와 API에는 인터넷이 필요하며, 제공된 페이지 API는 게시 후 사용할 수 있습니다.

## 주소와 배포

시민 화면은 `/main`, 공감순위는 `/ranking`, 처리현황은 `/status`, 자료조사는 `/research`, 이용안내는 `/guide`, 보관함은 `/activity`, 관리 화면은 `/admin` 주소로 직접 접속합니다. 시민 화면에는 관리 화면 링크가 없습니다. 기존 시민 화면 해시 주소도 이어집니다. ZIP을 풀 때 `index.html`, 각 경로의 `index.html`, `images` 폴더를 함께 같은 위치에 게시하세요. 경로별 파일은 메인 HTML을 같은 사이트에서 불러오는 작은 진입점이므로 정적 호스팅에서도 직접 접속과 새로고침을 지원합니다. 호스팅에 따라 디렉터리 주소 끝에 `/`가 붙을 수 있습니다. 사이트를 하위 폴더에 게시해도 해당 폴더 아래의 상대 경로를 사용합니다. HTML을 `file://`로 직접 열 때는 파일 시스템 경로를 바꿀 수 없어 관리자 화면에 `index.html#admin`을 직접 입력해 접근합니다. 경로를 숨기는 것은 접근 제어가 아닙니다.

## 관리 작업 화면

`/admin`에서 신고 목록과 공감·댓글 집계, 분야·진행 의견 필터, 제목·내용·위치 검색, 최신·오래된 순·공감·댓글·내 우선순위·확인 예정일 정렬을 사용할 수 있습니다. 신고를 선택하면 시민의 공개 댓글을 확인하고 공개 답글을 남길 수 있습니다. 진행 상황과 승인·반려 **제안**은 공개 기록으로 남기며 시민 신고 상세와 처리현황에서도 보입니다. 공개 기록과 댓글은 실시간 채팅이 아니며 최신 목록은 새로고침으로 확인합니다. 본인이 쓴 일반 진행 기록은 수정·삭제할 수 있습니다. 신고를 삭제하는 대신 처리 완료 또는 처리 다시 진행으로 변경할 수 있습니다. 관리 화면의 처리 완료 집계와 상태 필터, 시민 화면의 처리현황·신고 목록·상세가 같은 상태를 표시합니다. 신고의 사진·좌표와 ID 확인, 내용·좌표 복사, 공개 답변 문구도 지원합니다. 관리 화면에서는 시민 화면으로 이동하는 버튼을 표시하지 않습니다. Ctrl/Cmd+K는 관리 검색에 초점을 둡니다. 모바일 화면에서는 키보드 단축키 안내를 숨깁니다.

각 신고별 개인 업무 상태(대기·진행 중·완료), 우선순위, 확인 예정일, 태그, 체크리스트와 업무 메모는 보호 컬렉션 `admin-tasks`에 **본인만 볼 수 있는 비공개 항목**으로 저장합니다. 다른 사용자에게 공유되지 않습니다. 업무 상태·긴급·기한 지남·7일 이내·업무 미등록 빠른 필터와 초기화, 기한 집계는 계정별 개인 업무 기준입니다. 완료된 업무는 긴급·기한 집계에서 제외하며 날짜는 서울 기준입니다. CSV 내보내기는 현재 필터에 맞는 신고의 제목·분야·위치·내용·공감과 댓글 수·최신 진행 의견을 포함하며 비공개 업무 메모는 포함하지 않습니다. 신고 자체에 민감한 정보가 들어 있을 수 있으므로 내보낸 파일을 주의해서 다루세요.

**중요: 현재 API에는 관리자 역할·관리자 승인·권한 부여를 판별하는 기능이 없습니다.** 관리 화면의 가입은 일반 회원가입이며, 로그인한 모든 회원이 관리 화면에서 공개 진행 기록이나 답글을 작성하고 신고의 처리 상태를 바꿀 수 있습니다. 처리 완료는 이 사이트에서 공유한 상태이며 실제 행정기관의 처리를 인증하지 않습니다. 작성자를 인증된 관리자라고 표시하거나 실제 행정기관의 승인·접수로 취급하지 않습니다. 보호 컬렉션의 타인 신고를 수정하거나 삭제하는 관리자 권한도 없고, 관리자 전용 비공개 채팅이나 여러 담당자가 공유하는 비공개 업무함도 제공되지 않습니다. 진짜 관리자만의 접근 제어와 승인 처리에는 API 차원의 관리자 역할과 권한 검증이 필요합니다.

## 회원가입과 로그인

제공된 페이지별 회원가입·로그인 API를 사용합니다. 아이디는 한글·영문·숫자로 시작하는 3~64자이며 `.`, `_`, `@`, `-`를 사용할 수 있습니다. 비밀번호는 8~128자입니다. 페이지별 프로젝트 ID와 정규화한 아이디로 소금을 만들고, 제공된 규격대로 PBKDF2-SHA-256 500,000회로 변환한 credential을 인증 API에만 전송합니다. 원문 비밀번호와 credential은 게시물이나 브라우저 저장소에 저장하지 않습니다. credential 자체도 인증에 사용될 수 있는 민감한 값이므로 노출하지 않아야 합니다. 통신과 사이트는 HTTPS로 보호되어야 하며, 이 페이지에는 비밀번호 복구 기능이 제공되지 않습니다.

로그인 후 세션은 해당 탭의 `sessionStorage`에만 보관합니다. 새로고침 시 `getCurrentUser`로 확인하며 401이면 세션을 지우고 다시 로그인하도록 안내합니다. 로그아웃은 API 호출 후 세션을 제거합니다. 탭이나 브라우저 환경에 따라 세션이 유지되지 않을 수 있으며, 다른 탭이나 기기에서는 로그인해야 합니다. 공유 기기에서는 사용 후 로그아웃하세요. 세션은 브라우저 스크립트가 읽을 수 있으므로 스크립트 침해에도 보호되는 HttpOnly 쿠키가 아닙니다.

## 신고와 회원 데이터

새 **회원 신고와 회원 댓글**은 보호 컬렉션에 `public`으로 저장합니다. 누구나 읽을 수 있지만 API 계약상 작성한 회원만 수정·삭제할 수 있습니다. **회원 관심과 화면 설정**은 보호 컬렉션에 `private`으로 저장해 본인 세션으로 불러옵니다. 공감은 보호 컬렉션의 공개 항목으로 저장하고 소유자 기준으로 집계하므로 로그인한 계정에서 다시 확인할 수 있습니다. 보호 컬렉션의 접근 통제는 API가 수행합니다.

회원가입·로그인 또는 게스트 이름 설정 후 신고·댓글·공감·관심을 이용할 수 있습니다. 게스트는 고정된 `게스트#` 뒤의 이름을 직접 수정하며 게스트 식별자와 이름을 1년 쿠키에 저장합니다. 쿠키가 차단되거나 `file://`에서 사용할 수 없는 경우 localStorage에 저장을 시도합니다. 쿠키와 기기 식별자는 인증이 아니며 삭제·변조할 수 있습니다. 게스트 신고·댓글·공감·관심은 일반 공개 컬렉션을 사용하므로 누구나 읽고 API로 수정·삭제할 수 있습니다. 새 회원 신고·댓글·공감·관심은 보호 컬렉션에 저장합니다. 게스트와 회원의 활동은 자동 병합되지 않습니다. **일반 컬렉션과 회차 설정은 API 자체에서 로그인 검증을 하지 않으며 작성자 보호가 없습니다.**

사진은 PNG/JPG/GIF/WebP/AVIF 5MiB 이하만 업로드하고, 반환된 주소를 신고에 저장합니다. **사진 URL은 공개**이므로 민감한 사진을 올리지 마세요. 공개 신고·댓글에 개인정보를 입력하지 마세요. JSON 요청 본문 전체는 UTF-8 64KiB 이하입니다.

빈 목록은 정상이며 페이지별 목록을 `next_offset`이 null이 될 때까지 읽습니다. 수정 시 최신 항목과 revision을 읽고 변경된 필드만 합쳐 전체 데이터를 교체합니다. 충돌하면 새 버전을 읽어 알리고 입력을 유지하여 수동 재시도할 수 있습니다. 생성 응답이 유실되면 자동으로 다시 만들지 않고 목록에서 확인하도록 안내합니다. 가입 응답이 유실된 경우 중복 가입을 시도하지 않고 로그인으로 확인하도록 안내합니다. 401, 404, 409, 413, 429, 503과 네트워크 오류를 표시합니다.

회차 설정은 사이트에서 로그인한 회원이 변경할 수 있지만 API의 일반 공개 컬렉션에 저장됩니다. 회차 종료는 자동으로 수행되지 않고 종료 버튼을 눌렀을 때 상위 세 건을 기록합니다. 동시에 첫 회차를 시작하면 여러 항목이 만들어질 수 있습니다. 신고 상태는 이용자가 정리하는 공개 상태이지 행정기관 처리 상태가 아닙니다. 신고는 시청 민원으로 접수되지 않으므로 행정 처리가 필요한 경우 국민신문고 등 공식 창구를 이용하세요. 긴급 상황은 112 또는 119로 연락하세요.

신고 작성자의 보호 데이터는 다른 계정이 직접 수정할 수 없으므로, 처리 상태는 보호 `updates` 컬렉션에 공개 JSON 상태 변경 기록으로 별도 저장합니다. 화면은 신고와 상태 기록을 함께 읽고 최신 상태를 적용하며 원본 신고는 삭제하거나 덮어쓰지 않습니다. 되돌릴 때는 새로운 처리 재개 기록을 추가합니다. 응답이 유실되면 저장 확인 후 재시도하며, 동시 변경은 기록의 순번과 서버 생성 시각 및 ID로 결정합니다. 서버가 관리자 역할을 검증하지 않으므로 전용 관리자만 상태를 변경하도록 강제하려면 서버 권한 기능이 필요합니다.

## 언어

한국어, 영어, 베트남어, 크메르어, 중국어(간체), 태국어, 러시아어, 일본어를 선택할 수 있습니다. 언어 선택 또는 상단의 **자동 번역 켜기**로 동의하면 API 키가 필요 없는 [MyMemory 공개 번역 API](https://mymemory.translated.net/doc/spec.php)를 사용해 시민 화면의 일부 문구와 공개 신고 제목·내용·댓글·공개 진행 의견을 선택한 언어로 번역합니다. 한국어 화면에서 외국어 게시물을 번역하려면 상단 버튼으로 켜세요. 새로 생긴 텍스트도 번역하고 끄면 원문을 복원합니다. 입력값·계정명·위치·관리 화면과 비공개 업무 메모는 자동 전송하지 않습니다. 내장 사전에 없는 문구나 입력 폼 등은 번역되지 않을 수 있습니다.

**개인정보:** 동의 후 공개 게시물 텍스트가 브라우저에서 MyMemory로 전송되며 서비스 제공자가 장기간 저장할 수 있습니다. 공개 게시물에도 민감한 정보가 포함될 수 있으므로 사용자가 켜기 전에 이를 안내합니다. MyMemory의 [약관·개인정보 정책](https://mymemory.translated.net/terms-and-conditions)을 확인하세요. 사용하지 않으려면 번역을 끄면 됩니다. 번역 결과는 원본 데이터에 저장되지 않습니다.

서비스의 익명 사용량은 통상 하루 5,000자이며 변경될 수 있습니다. 요청당 500바이트 제한에 맞춰 나누고, 중복 캐시와 동시 요청 제한을 사용합니다. 서비스 한도와 브라우저 통신 오류, 언어 감지나 번역 품질에 따라 일부 텍스트가 번역되지 않을 수 있으며 이때 원문을 표시합니다. MyMemory의 `autodetect` 동작은 공식 API 명세에 명시되어 있지 않아 변경될 수 있습니다. 테스트에서 실제 서비스 응답은 확인했지만 배포 사이트의 브라우저 CORS 연결은 확인하지 못했습니다.

## 지도와 이미지

MapLibre GL JS와 OpenFreeMap 공개 벡터 지도를 사용합니다. 지도에는 인터넷과 WebGL이 필요하며 연결 실패 시 목록·검색·좌표 직접 입력은 계속 사용할 수 있습니다. ZIP에 포함된 분야별 이미지와 삽화는 AI 생성 이미지입니다. 새로 올린 사진은 API가 반환한 주소로 표시됩니다.

## 개발 및 검증

```bash
npm ci
npm run dev
npm run build
npm test
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

모의 API 단위·브라우저 테스트는 회원가입·로그인·새로고침·로그아웃, 계정 전환, 공개/비공개 가시성, 작성자 권한, 일반 신고 호환, 페이지네이션, 수정 충돌, 오류 시 입력 보존, 응답 유실과 비밀번호 원문 미전송을 확인합니다. 게스트 이름 수정과 쿠키 복원, 게스트의 신고·공감·댓글, 로그인 후 작성 화면 복귀, 언어 선택과 동의 전 전송 금지, 모의 번역·원문 복원을 확인합니다. 관리 화면의 처리 완료·재개, 다른 작성자의 신고와 비로그인 시민 화면 반영, 응답 유실 확인, 경로별 직접 접속·새로고침, 검색·필터·공개 대화·진행 의견·비공개 업무 상태·기한·체크리스트·CSV·진행 기록 수정·충돌과 응답 유실도 모의 API로 확인했습니다. 실제 API와 게시된 사이트의 CORS·인증·권한 적용 및 외부 지도 서비스는 검증하지 않았습니다. 배포 ZIP에는 HTML과 이미지 파일만 포함됩니다.
