# 충주잇다

충주시민 생활불편 공감신고를 체험하는 정적 웹앱입니다. **공식 민원 접수 창구가 아니며**, 예시 민원과 처리 상태는 실제 접수 내역이 아닙니다. 회차와 시청 전달 안내는 운영 방식 예시이며 실제로 전달되지 않습니다. 예시 위치는 동네의 대략적인 대표 좌표입니다.

## 실행 및 빌드

```bash
npm install
npm run dev       # 표시되는 로컬 주소에서 실행
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 확인
```

Vite와 일반 JavaScript만 사용합니다. 게스트 이름, 공감 기록, 테스트 신고 및 사진은 브라우저의 localStorage에만 보관됩니다. 데이터가 없거나 손상되면 예시 데이터로 복구합니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 저장 용량을 초과하거나 저장이 차단된 경우 안내가 표시됩니다. 신고 위치는 지도 연결 시 주소 검색을 시도하고 찾지 못하면 충주시 중심에 표시합니다. 개인정보나 민감한 사진은 입력하지 마세요.

## Google 지도 설정

지도는 공식 Google Maps JavaScript API를 사용합니다. **키 설정 전이나 권한이 없을 때는 지도가 로딩되지 않습니다.** 키가 없어도 목록 등 다른 기능은 사용할 수 있습니다. 이 저장소에는 키가 들어 있지 않습니다.

1. Google Cloud에서 프로젝트를 만들고 결제를 연결한 뒤 **Maps JavaScript API**를 활성화합니다. 신고 위치 주소 검색을 사용하려면 **Geocoding API**도 활성화합니다.
2. API 키를 만들고 애플리케이션 제한을 **웹사이트(HTTP 리퍼러)**로 설정합니다. 예를 들어 `http://localhost:5173/*`, `http://127.0.0.1:5173/*`, 미리보기 포트의 주소 및 운영 주소 `https://example.com/*`를 실제 환경에 맞게 추가합니다. 하위 도메인·포트·프로토콜도 확인하세요. API 제한에는 사용하는 Maps JavaScript API와 Geocoding API만 허용합니다.
3. 로컬 개발 시 `public/config.js`의 `googleMapsApiKey`에 키를 넣습니다. **실제 키를 저장소에 커밋하지 마세요.** 배포 시에는 빌드된 `dist/config.js`를 안전한 배포 환경에서 수정할 수도 있습니다. 브라우저용 키는 사용자에게 노출되므로 리퍼러/API 제한, 할당량 및 사용량 모니터링이 필수입니다.
4. HTTPS 운영 도메인과 실제 접속 경로를 브라우저에서 열어 지도가 표시되는지 확인하고, Google Cloud 키의 웹사이트 제한에 해당 도메인이 포함되었는지 확인합니다. 설정 변경은 반영까지 시간이 걸릴 수 있습니다.

### 지도 오류 확인

- **키 미설정:** `config.js`에 키를 입력하고 새로고침하세요.
- **인증 오류:** 브라우저 개발자 도구 콘솔의 Google Maps 오류 코드와 Cloud Console을 확인하세요. `RefererNotAllowedMapError`는 리퍼러 제한, `ApiNotActivatedMapError`는 API 활성화, `BillingNotEnabledMapError`는 결제 설정, `InvalidKeyMapError`는 키를 확인합니다. SDK는 모든 인증 원인을 앱에 구분해서 전달하지 않으므로 화면에는 가능한 원인을 함께 안내합니다.
- **네트워크 오류:** 인터넷 연결, 방화벽, 광고 차단기 및 Google 도메인 접근을 확인하고 다시 시도하세요.
- 주소 검색에 실패해도 테스트 신고는 저장되며 지도에는 충주시 중심이 표시됩니다.

## ZIP 및 정적 배포

```bash
npm run build
(cd dist && zip -r ../chungju-eatda-dist.zip .)
```

ZIP에는 `dist` 폴더 자체가 아닌 내용물이 담겨 있어 압축을 풀면 `index.html`이 바로 보입니다. 상대 경로를 사용하므로 HTTPS 정적 호스팅의 하위 경로에도 배포할 수 있습니다. ES 모듈과 브라우저 보안 정책 때문에 `index.html`을 `file://`로 직접 열지 말고 정적 서버를 사용하세요. 예: 압축을 푼 폴더에서 `python3 -m http.server 8000`, 브라우저에서 `http://localhost:8000/`. 실제 배포는 HTTPS를 사용하고 위의 지도 키 도메인 제한을 확인하세요.

## 사진

`public/images/`의 8개 사진은 이 프로젝트를 위해 AI 이미지 생성 기능으로 제작한 예시 이미지입니다. 실제 충주 현장이나 신고 사진이 아닙니다. 빌드 시 로컬 파일이 `dist/images/`에 복사되며 외부 이미지 서버에 의존하지 않습니다. 사진 로딩 실패 시 로컬 `station.jpg`를 대체 이미지로 사용합니다.
