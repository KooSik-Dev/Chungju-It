# 충주잇다

충주시 생활 불편 이야기를 둘러보고 기록하는 단일 HTML 웹앱입니다. 지도, 검색, 공감, 관심, 메모, 회차와 로컬 계정을 제공합니다. 기본 이야기의 사건·진행 상태는 실제 접수 내역이 아니며 신고를 시청에 전달하지 않습니다.

## 실행과 계정

1. ZIP을 풀고 `index.html`을 데스크톱 Chrome 또는 Edge로 엽니다. 지도에는 인터넷이 필요합니다.
2. 상단 **로그인 → 회원가입 → 폴더 선택**을 누르고 기록을 보관할 폴더를 선택한 뒤 브라우저의 접근 요청을 허용합니다.
3. 이름과 8자 이상의 비밀번호로 가입합니다. 다음에 다시 열 때는 **같은 폴더**를 선택하고 이름과 비밀번호로 로그인합니다. 페이지를 다시 열면 다시 로그인해야 합니다.
4. 로그인한 계정의 신고, 공감, 관심, 메모, 비교함, 회차와 설정은 선택한 폴더에 저장됩니다. 계정별 기록은 서로 분리되며 다른 계정과 자동 공유되지 않습니다. 로그인하지 않은 게스트 기록은 기존처럼 브라우저에만 저장됩니다. 기존 게스트 기록은 신규 계정에 자동으로 복사되지 않습니다.

폴더 구조:

```text
선택한 폴더/
  data/accounts.json          # 계정 이름, 랜덤 소금, PBKDF2-SHA-256 비밀번호 해시
  data/users/<계정ID>.json  # 계정별 신고와 활동, 회차 및 설정
  img/<사진해시>.jpg|png|webp|gif
```

신고 사진은 1MB 이하 JPG/PNG/WEBP/GIF를 선택하세요. 이미지 파일을 먼저 저장하고 JSON에 상대 경로를 기록합니다. 이미지를 교체하거나 신고를 삭제해도 이전 이미지 파일은 안전을 위해 자동 삭제하지 않습니다. 상단의 폴더 저장 상태가 **저장됨**으로 바뀐 뒤 창을 닫으세요. 실패하면 프로필의 **다시 저장**을 누르세요. 쓰기가 실패한 상태에서는 로그아웃이 차단되며, 페이지 종료 시 경고를 표시합니다. 강제 종료나 브라우저 충돌 시 저장 중이던 내용은 유실될 수 있습니다.

로컬 폴더 접근은 File System Access API를 지원하는 데스크톱 Chrome/Edge와 보안 컨텍스트(`file://`, HTTPS 또는 localhost)에서 사용할 수 있습니다. 폴더 선택·쓰기 권한을 허용해야 하며 브라우저 정책에 따라 재승인이 필요합니다. 모바일, Safari, Firefox 등에서는 폴더 저장을 지원하지 않을 수 있습니다. 폴더는 브라우저에서 선택한 로컬 폴더이며 별도 동기화를 설정하지 않으면 다른 기기에 복사되지 않습니다. 동시 편집은 지원하지 않으므로 같은 폴더를 여러 탭이나 기기에서 동시에 사용하지 마세요.

비밀번호는 원문 대신 임의 소금과 PBKDF2-SHA-256(210,000회) 해시로 저장하며 복구 기능은 없습니다. **폴더의 파일에 직접 접근할 수 있는 사람에게 기록을 숨기거나 변경을 막는 암호화 기능은 아닙니다.** `data`와 `img`를 안전한 위치에 함께 백업하세요. 공개 웹 폴더에 계정 파일·사진을 올리면 누구나 볼 수 있으므로 올리지 마세요.

## 지도와 기본 콘텐츠

MapLibre GL JS와 OpenFreeMap의 공개 벡터 지도를 사용합니다. 지도 라이브러리는 HTML에 포함되지만 지도 데이터에는 인터넷과 WebGL이 필요합니다. 지도 실패 시 목록·검색 등 다른 기능을 사용할 수 있고 재시도할 수 있습니다. 실제 서비스 가용성은 외부 제공자에 달려 있습니다.

기본 9건은 기획 스토리이고 사진과 삽화는 프로젝트를 위해 AI로 생성한 이미지로 실제 현장 사진이 아닙니다. 충주역·충주공용버스터미널·호암지의 대표 위치는 각각 [충주역](https://rail.blue/railroad/logis/stationinfo.aspx?id=701), [충주공용버스터미널](https://mapcarta.com/N368736335), [호암지](https://info.koreacharts.com/tour/125871/contents.html)를 참고했습니다. 위치는 대표 지점이며 실제 사건을 확인한 것이 아닙니다.

## 사용 기능과 제한

검색·필터·정렬·숫자 TOP 3 지도·상세·공감·관심·개인 메모·이야기 비교·공유·한영 전환을 제공합니다. 신고 작성 중 텍스트와 좌표는 같은 탭의 임시 글로 저장되지만 사진은 포함하지 않습니다. 회차는 기기 시간을 기준으로 페이지가 열려 있거나 다시 열릴 때 갱신됩니다. 기본 스토리의 상태는 실제 처리 상황이 아닙니다. 긴급 상황은 112 또는 119, 행정 민원은 국민신문고 등 공식 창구를 이용하세요.

보관함의 백업/복원은 신고·사진·공감·관심·메모를 JSON으로 내보내거나 복원합니다. 회차와 설정, 계정 비밀번호는 별도의 폴더 기록에 있으며 백업 기능에는 포함되지 않습니다. 복원은 현재 계정의 기록을 교체합니다. 파일에는 개인정보가 포함될 수 있으므로 주의하세요.

## 개발 및 검증

```bash
npm ci
npm run dev
npm run build            # dist/index.html 하나에 코드·스타일·기본 이미지 포함
npm test
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

브라우저 테스트는 폴더 선택을 모킹하고 가입·비밀번호·JSON·사진·저장 실패 및 재시도·재로그인을 검증합니다. 단위 테스트는 임시 디렉터리에 실제 JSON과 이미지 파일을 쓰고 다시 읽습니다. 지도 테스트는 지도 스타일을 모킹하므로 외부 지도 서비스의 실제 가용성은 검증하지 않습니다. 배포 ZIP에는 HTML과 이미지 파일만 포함됩니다. 사용 시 생성되는 JSON과 업로드 사진은 사용자가 선택한 폴더에 저장됩니다.
