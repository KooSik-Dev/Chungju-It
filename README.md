# 충주잇다

충주시 생활 불편 이야기를 둘러보고 기록하는 단일 HTML 웹앱입니다. 기본 이야기와 진행 상태는 실제 접수 내역이 아닙니다. 신고는 사이트 관리자에게 전달되며 시청 민원으로 접수되지는 않습니다.

## 페이지 API와 신고

신고 전송 시 사용자가 입력한 분야·제목·내용·위치·좌표 및 식별자와 시각을 페이지 API로 JSON POST합니다. 사진을 선택하면 먼저 `file` 필드의 multipart/form-data로 업로드하고 응답의 HTTPS 이미지 URL을 신고 데이터에 넣습니다. 사진은 PNG/JPG/GIF/WebP/AVIF, 5MB 이하이며 JSON은 UTF-8 기준 64KB 이하입니다. 비밀번호, 비밀번호 해시, 계정 이름, 개인 메모나 전체 브라우저 저장 데이터는 API에 보내지 않습니다. 신고 내용이나 사진 자체에 비밀번호·민감한 정보가 들어가지 않도록 주의하세요.

화면에서 사진 업로드 및 신고 전송 상태와 오류를 확인할 수 있으며 실패해도 입력은 유지됩니다. 업로드만 성공하고 신고 전송이 실패하면 같은 사진의 업로드 주소를 재사용해 재시도합니다. 네트워크 오류 또는 응답 손상 시 상대방이 이미 처리했을 가능성이 있어 중복될 수 있습니다. 전송 성공 후 브라우저 저장이 실패한 경우 중복 전송을 막고 화면에 알립니다. 전송 후 브라우저에서 신고를 삭제해도 관리자에게 이미 전달된 데이터가 삭제되지는 않습니다.

이 API는 제공된 **일단 테스트임 아마** 페이지 전용입니다. 제공된 페이지 토큰은 공개 페이지에 포함되는 쓰기 전용 값으로 비밀이 아니며, 누구나 이를 이용해 쓰기 요청을 시도할 수 있습니다. 민감한 정보는 전송하면 안 됩니다. 실제 환경에서는 CORS가 이 사이트의 출처를 허용해야 합니다. 페이지 주소나 토큰이 바뀌면 `src/page-api.js`에서 구성값을 갱신하여 다시 빌드해야 합니다.

제공된 API에는 조회·계정 인증·수정·삭제 규격이 없으므로, 신고를 다른 방문자의 화면에 불러오거나 계정과 공감 수를 기기 간에 동기화하지 않습니다. 수정 신고는 기존 항목을 직접 변경하는 것이 아니라 새 `report.updated` JSON 이벤트로 전달합니다. 공감·관심·메모와 계정은 이 브라우저에만 보관됩니다. 실제 계정 공유나 공감 집계를 구현하려면 별도의 읽기 및 인증 기능이 필요합니다.

## 실행과 계정

ZIP을 풀고 `index.html`을 브라우저에서 엽니다. **로그인 → 회원가입**에서 이름과 비밀번호를 입력하면 폴더를 선택하지 않고 계정이 만들어집니다. 비밀번호는 8자 이상이며 잊으면 복구할 수 없습니다. 다시 로그인하면 이 브라우저에 저장된 계정별 신고, 공감, 관심, 메모, 비교함, 회차와 설정을 불러옵니다. 서로 다른 계정의 활동은 분리됩니다. 기존 게스트 기록은 신규 계정에 자동 복사되지 않습니다.

계정과 활동은 **현재 브라우저의 이 사이트 전용 저장 공간**에 보관됩니다. 브라우저 데이터를 지우거나 저장 공간을 초기화하면 계정과 기록도 삭제될 수 있습니다. 다른 브라우저·기기·사이트 주소에는 자동으로 공유되지 않습니다. 폴더를 수동 선택하던 이전 버전의 외부 폴더 기록도 자동으로 옮겨지지 않습니다. 강제 종료 시 저장 중이던 변경은 유실될 수 있으므로 상단에 **저장됨**이 표시된 뒤 창을 닫으세요. 저장 실패 시 프로필에서 **다시 저장**을 누르세요.

브라우저 내부 Origin Private File System에 `data/accounts.json`과 `data/users/<계정ID>.json`이 자동 생성됩니다. 과거 브라우저에 보관된 사진은 내부 `img/`에 보관되며 새로 전송한 사진은 API에서 반환한 주소로 표시됩니다. 이 파일은 운영체제 파일 탐색기에서 HTML 옆에 보이는 파일이 아닙니다. OPFS가 제한된 환경(일부 `file://` 포함)에서는 IndexedDB에 같은 경로의 가상 JSON과 이미지 Blob으로 보관합니다. 여러 탭에서 동시에 편집하면 덮어쓰기가 생길 수 있으니 한 탭에서 사용하세요.

비밀번호는 원문 대신 임의 소금과 PBKDF2-SHA-256(210,000회) 해시로 보관하지만 **활동과 사진을 암호화하지는 않습니다.** 브라우저의 저장 공간에 접근할 수 있는 사람은 기록을 볼 수 있습니다. 보관함의 백업 기능은 신고·공감·관심·메모를 JSON으로 내보내지만 계정·비밀번호·회차·설정은 포함하지 않습니다. 업로드된 사진은 이미지 파일 자체가 아니라 외부 URL로 포함되므로 원본 사진도 따로 보관하세요.

## 지도와 기본 콘텐츠

MapLibre GL JS와 OpenFreeMap의 공개 벡터 지도를 사용합니다. 라이브러리는 HTML에 포함되지만 지도 데이터에는 인터넷과 WebGL이 필요합니다. 지도를 불러오지 못해도 목록·검색 등을 사용할 수 있습니다. 기본 9건은 기획 스토리이며 사진과 삽화는 AI 생성 이미지입니다. 충주역·충주공용버스터미널·호암지의 대표 위치는 각각 [충주역](https://rail.blue/railroad/logis/stationinfo.aspx?id=701), [충주공용버스터미널](https://mapcarta.com/N368736335), [호암지](https://info.koreacharts.com/tour/125871/contents.html)를 참고했습니다. 대표 위치는 실제 사건을 확인한 것이 아닙니다.

## 기능과 제한

검색·필터·정렬·숫자 TOP 3 지도·상세·공감·관심·메모·비교·공유·한영 전환을 제공합니다. 신고 작성 중 텍스트와 좌표는 같은 탭의 임시 글로 저장되지만 사진은 포함하지 않습니다. 회차는 기기 시간을 기준으로 페이지가 열려 있거나 다시 열릴 때 갱신됩니다. 긴급 상황은 112 또는 119, 행정 민원은 국민신문고 등 공식 창구를 이용하세요.

## 개발 및 검증

```bash
npm ci
npm run dev
npm run build
npm test
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

빌드 결과는 HTML 하나에 코드·스타일·기본 이미지가 포함됩니다. 브라우저 테스트는 페이지 API의 JSON·사진 요청과 오류를 모킹하고, 브라우저 전용 파일 저장소 및 `file://`의 IndexedDB 대체 경로를 확인합니다. API 실제 접속·CORS와 외부 지도 서비스 가용성은 테스트 환경의 네트워크 제한으로 검증하지 않았습니다. 배포 ZIP에는 HTML과 이미지 파일만 포함됩니다.
