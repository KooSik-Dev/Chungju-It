# 충주잇다

충주시 생활 불편 이야기를 둘러보고 기록하는 단일 HTML 웹앱입니다. 기본 이야기와 진행 상태는 실제 접수 내역이 아니며, 신고가 시청에 전달되지는 않습니다.

## 실행과 계정

ZIP을 풀고 `index.html`을 브라우저에서 엽니다. **로그인 → 회원가입**에서 이름과 비밀번호를 입력하면 폴더를 선택하지 않고 계정이 만들어집니다. 비밀번호는 8자 이상이며 잊으면 복구할 수 없습니다. 다시 로그인하면 계정별 신고, 공감, 관심, 메모, 비교함, 회차와 설정을 불러옵니다. 서로 다른 계정의 활동은 분리됩니다. 기존 게스트 기록은 신규 계정에 자동 복사되지 않습니다.

계정과 활동, 신고 사진은 **현재 브라우저의 이 사이트 전용 저장 공간**에 보관됩니다. 브라우저 데이터를 지우거나 저장 공간을 초기화하면 계정과 기록도 삭제될 수 있습니다. 다른 브라우저·기기·사이트 주소에는 자동으로 공유되지 않습니다. 폴더를 수동 선택하던 이전 버전의 외부 폴더 기록도 자동으로 옮겨지지 않습니다. 강제 종료 시 저장 중이던 변경은 유실될 수 있으므로 상단에 **저장됨**이 표시된 뒤 창을 닫으세요. 저장 실패 시 프로필에서 **다시 저장**을 누르세요.

보안상의 이유로 일반 웹 문서는 HTML이 놓인 실제 폴더 옆의 파일을 임의로 수정할 수 없습니다. 별도 폴더 선택 없이 작동하도록 브라우저 내부의 Origin Private File System에 아래 파일을 자동으로 만듭니다. **이것은 운영체제 파일 탐색기에서 HTML 옆에 보이는 폴더가 아니며, 배포된 사이트 파일을 수정하지도 않습니다.** OPFS가 제한된 환경(일부 `file://` 포함)에서는 IndexedDB에 같은 경로의 가상 JSON과 이미지 Blob으로 보관합니다.

```text
브라우저 전용 저장 공간/
  data/accounts.json          # 계정 이름, 소금, PBKDF2-SHA-256 비밀번호 해시
  data/users/<계정ID>.json  # 계정별 활동과 설정
  img/<사진해시>.jpg|png|webp|gif
```

신고 사진은 1MB 이하 JPG/PNG/WEBP/GIF를 선택하세요. 이미지 파일을 먼저 저장하고 JSON에 이미지 경로를 기록합니다. 이미지를 교체하거나 신고를 삭제해도 이전 이미지가 저장 공간에 남을 수 있습니다. 하나의 저장 공간을 여러 탭에서 동시에 편집하면 덮어쓰기가 생길 수 있으니 한 탭에서 사용하세요.

비밀번호는 원문 대신 임의 소금과 PBKDF2-SHA-256(210,000회) 해시로 보관하지만 **활동과 사진을 암호화하지는 않습니다.** 이 브라우저의 저장 공간에 접근할 수 있는 사람은 기록을 볼 수 있습니다. 사적인 정보나 민감한 사진을 입력하지 마세요. 보관함의 백업 기능으로 신고와 사진·공감·관심·메모를 JSON으로 내보낼 수 있지만, 계정·비밀번호·회차·설정은 백업에 포함되지 않습니다.

## 지도와 기본 콘텐츠

MapLibre GL JS와 OpenFreeMap의 공개 벡터 지도를 사용합니다. 라이브러리는 HTML에 포함되지만 지도 데이터에는 인터넷과 WebGL이 필요합니다. 지도를 불러오지 못해도 목록·검색 등을 사용할 수 있습니다. 기본 9건은 기획 스토리이며 사진과 삽화는 AI 생성 이미지입니다. 충주역·충주공용버스터미널·호암지의 대표 위치는 각각 [충주역](https://rail.blue/railroad/logis/stationinfo.aspx?id=701), [충주공용버스터미널](https://mapcarta.com/N368736335), [호암지](https://info.koreacharts.com/tour/125871/contents.html)를 참고했습니다. 대표 위치는 실제 사건을 확인한 것이 아닙니다.

## 기능과 제한

검색·필터·정렬·숫자 TOP 3 지도·상세·공감·관심·메모·비교·공유·한영 전환을 제공합니다. 신고 작성 중 텍스트와 좌표는 같은 탭의 임시 글로 저장되지만 사진은 포함하지 않습니다. 회차는 기기 시간을 기준으로 페이지가 열려 있거나 다시 열릴 때 갱신됩니다. 긴급 상황은 112 또는 119, 행정 민원은 국민신문고 등 공식 창구를 이용하세요.

## 개발 및 검증

```bash
npm ci
npm run dev
npm run build
npm test
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

빌드 결과는 HTML 하나에 코드·스타일·기본 이미지가 포함됩니다. 브라우저 테스트는 Chromium의 실제 브라우저 전용 파일 저장소에서 가입·로그인·JSON·사진·오류 복구를 확인하고, `file://`의 IndexedDB 대체 경로도 확인합니다. 지도 테스트는 스타일을 모킹하므로 외부 지도 서비스의 실제 가용성은 검증하지 않습니다. 배포 ZIP에는 HTML과 이미지 파일만 포함됩니다.
