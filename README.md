# 충주잇다

충주 생활 불편을 함께 살펴보는 단일 HTML 사이트입니다. ZIP을 풀고 `index.html`을 게시하거나 브라우저에서 엽니다. 지도 데이터와 페이지 API에 연결하려면 인터넷이 필요하며, API는 제공자가 페이지를 게시한 뒤 사용할 수 있습니다.

## 공유 컬렉션과 사진

제공된 페이지 API와 공개 토큰을 사용합니다. 신고(`reports`), 댓글(`comments`), 공감(`supports`), 관심(`favorites`), 표시명·화면 설정(`profiles`), 회차(`rounds`)를 각각 컬렉션에 저장하고 목록을 끝까지 페이지별로 읽습니다. 빈 컬렉션은 정상적인 빈 목록이며, 불러오기 실패는 상단에 표시하고 다시 시도할 수 있습니다. 예전 기획 이야기나 이전 기기에 저장된 신고는 공유 컬렉션에 자동으로 삽입하거나 이전하지 않습니다.

사진은 PNG/JPG/GIF/WebP/AVIF 5MiB 이하만 업로드하고, 반환된 HTTPS 주소를 신고에 저장합니다. JSON 요청 본문 전체는 UTF-8 64KiB 이하입니다. 업로드는 성공하고 신고 저장은 실패했다면 선택한 사진의 주소를 재사용합니다. 업로드 결과를 받지 못하면 고아 이미지가 남을 수 있습니다.

수정은 최신 항목을 읽고 나머지 필드를 보존해 전체 데이터를 교체합니다. 수정이나 삭제가 경합하면 최신 데이터를 읽어 알리고 사용자 확인 후 다시 시도합니다. 기존 항목에 비밀번호 관련 필드가 있으면 수정하지 않습니다. 네트워크 오류·응답 손실 또는 일부 서버 오류로 생성 결과가 불확실하면 자동 재생성하지 않고 목록을 확인하게 합니다. 항목이 목록에 아직 나타나지 않는 경우에도 중복 가능성이 있으므로 다시 저장하기 전 충분히 확인해야 합니다.

## 공개 데이터와 인증 한계

**이 API는 사용자 인증이나 사용자별 접근 권한을 제공하지 않습니다.** 토큰은 HTML에 공개되어 있으며 누구든 신고, 댓글, 사진 주소, 공감, 관심, 표시명과 설정을 읽거나 수정·삭제할 수 있습니다. 비밀번호나 개인정보, 민감한 사진은 입력하지 마세요. 표시명은 인증이 아니며 이름이나 비밀번호를 이용한 회원가입·로그인은 제공하지 않습니다. 브라우저별 임의 식별자는 공감 중복 방지와 관심 표시의 편의를 위한 것으로 위조·복제·삭제가 가능하며 보안 수단이 아닙니다. 다른 브라우저에서는 같은 사람의 관심과 설정이 자동 연결되지 않습니다.

회차 설정도 공개되며 누구나 변경할 수 있습니다. 회차 종료는 자동으로 수행되지 않고 화면의 종료 버튼을 눌렀을 때 상위 세 건을 기록합니다. 동시에 첫 회차를 시작하면 API에 고유성 보장이 없어 여러 항목이 생길 수 있습니다. 신고 상태는 이용자가 정리하는 공개 상태이며 행정기관의 처리 여부가 아닙니다. 신고는 시청 민원으로 접수되지 않으므로 행정 처리가 필요한 경우 국민신문고 등 공식 창구를 이용하세요. 긴급 상황은 112 또는 119로 연락하세요.

언어·글자 크기·진동·비교함 설정은 공개 표시명 항목에 저장하며, 초기 화면을 위한 브라우저 설정도 보조적으로 사용합니다. 작성 중인 신고 텍스트는 같은 탭의 임시 글에 남지만 사진은 임시 저장되지 않습니다. 기기 식별자나 임시 글은 브라우저 데이터를 지우면 사라질 수 있습니다.

## 지도와 이미지

MapLibre GL JS와 OpenFreeMap 공개 벡터 지도를 사용합니다. 지도에는 인터넷과 WebGL이 필요하며 연결 실패 시 목록·검색·좌표 직접 입력은 계속 사용할 수 있습니다. ZIP에 포함된 분야별 이미지와 삽화는 AI 생성 이미지입니다. 새로 올린 사진은 API가 반환한 주소로 표시됩니다.

## 개발 및 검증

```bash
npm ci
npm run dev
npm run build
npm test
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

브라우저 테스트는 API를 모킹하여 빈 목록, 여러 페이지, 별도 브라우저에서 다시 읽기, 사진 업로드, 생성·수정·삭제, 409 충돌, 오류 시 입력 보존, 응답 유실 시 중복 방지와 비밀번호 미전송을 검증합니다. 실제 API와 게시된 사이트의 CORS, 외부 지도 서비스는 검증하지 않았습니다. 실제 환경에서는 API가 게시된 사이트 출처 및 로컬 파일 출처의 CORS 요청을 허용해야 합니다. 배포 ZIP에는 HTML과 이미지 파일만 포함됩니다.
